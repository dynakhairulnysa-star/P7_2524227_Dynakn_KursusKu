# KursusKu

Project praktikum Pemrograman Web III.

## Cara Menjalankan
1. Buka terminal pada folder project.
2. Jalankan: `composer install`
3. Jalankan: `php artisan serve`
4. Buka alamat yang ditampilkan terminal.
